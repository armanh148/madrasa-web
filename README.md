# مدرسہ صاحب الزمان (عجل اللہ تعالیٰ فرجہ الشریف)
## Madarsa e Sahib uz Zaman — Official Web Portal

ایک جدید، ریسپانسو اور پروقار اسلامی تعلیمی پورٹل جو **Next.js 15 (App Router)**، **TypeScript**، اور **Tailwind CSS** پر تیار کیا گیا ہے۔

---

### 🎨 خصوصیات (Key Features)

- **شاہی اور روایتی اسلامی تھیم:** Dark Browns (`#150B08`, `#2E1B15`)، Royal Gold (`#D4AF37`) اور Soft Cream۔
- **مکمل RTL اور اردو ٹائپوگرافی:** `Amiri` اور `Noto Nastaliq Urdu`۔
- **ہیرو سیکشن:** شفق کے وقت مدرسہ کی عمارت، بسم اللہ شریف، اور دعائے فرج۔
- **تعلیمی شعبہ جات:** درسِ نظامی، حفظ و تجوید، عقائد و اخلاقیات، اور عصری آئی ٹی علوم۔
- **جامعہ سیدہ فاطمہ الزہراء (س):** خواتین کے لیے مخصوص اور پردہ دار کیمپس۔
- **دسترخوانِ امام زمانہ (عج):** روزانہ طعام، سحر و افطار، اور کفالتِ طلباء۔
- **مرکزی کتب خانہ:** ۲۵,۰۰۰+ نایاب و مطبوعہ کتب۔
- **حقوقِ شرعیہ و صدقات:** میزان بینک اور والٹ اکاؤنٹس مع ون کلک کاپی بٹن۔
- **آن لائن داخلہ فارم:** یونیک ایپلیکیشن آئی ڈی جنریٹر کے ساتھ انٹرایکٹو ماڈل۔

---

### 🚀 انسٹالیشن اور لوکل سیٹ اپ (Installation)

```bash
# ریپازٹری کلون کریں
git clone https://github.com/syedjawwad313/madrasa-web.git

# فولڈر میں جائیں
cd madrasa-web

# پیکجز انسٹال کریں
npm install

# ڈویلپمنٹ سرور چلائیں
npm run dev
```

براؤزر میں کھولیں: [http://localhost:3000](http://localhost:3000)

---

### 🛠️ ٹیکنالوجیز (Tech Stack)

- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Fonts:** Google Fonts (Amiri, Noto Nastaliq Urdu)
